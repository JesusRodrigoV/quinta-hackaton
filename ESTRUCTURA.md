# Estructura del Proyecto - Quinta Hackaton

Este repositorio contiene la base para el proyecto de la Quinta Hackaton.

## Directorios y Archivos Actuales

- `.gitignore`: Archivo para ignorar archivos no deseados en Git.
- `README.md`: Documentación inicial del proyecto.

## Propuesta de Estructura Sugerida

Para el desarrollo de la hackaton, se sugiere la siguiente organización:

```text
/
├── frontend/          # Código de la interfaz de usuario (React, Vue, etc.)
├── backend/           # API y lógica de servidor (Node.js, Python, etc.)
├── docs/              # Documentación adicional, diagramas y diseños
├── tests/             # Pruebas unitarias e integrales
└── ESTRUCTURA.md      # Este archivo (documentación de la estructura)
```
